   106→   106→Key Findings (high-signal summary):
   107→   107→1. **100ms rule is non-negotiable** — every keystroke must paint in <100ms or the app is "keyboard-capable" not "keyboard-first" (Nielsen, UX Tigers). LCKED's decrypt-on-search must stay off the main thread.
   108→   108→2. **LCKED's `⌘L` for lock collides with the browser URL bar** (every Chromium/Firefox). Should rebind to `⌘⇧L` (matches 1Password).
   109→   109→3. **1Password's modifier-tiered copy pattern** (`⌘C` username / `⇧⌘C` password / `⌥⌘C` OTP) is the single highest-impact pattern LCKED is missing. Same verb, three tiers.
   110→   110→4. **1Password's hold-`⌥` quasimode reveal** is safer than LCKED's toggle button — release to re-mask, can't be left on by accident.
   111→   111→5. **Frecency + favorites (`⌘1`–`⌘9`)** beat LCKED's current fuzzy-only palette. Muscle-memory routes must be deterministic (Raycast's strict alias matching is the principle).
   112→   112→6. **`?` context-aware cheat sheet** missing from LCKED — universal pattern (Superhuman/GitHub/Vimium/Notion).
   113→   113→7. **Spatial arrow routing** between list (`↑↓`) and detail (`←→`) via roving tabindex — the 1Password signature; LCKED currently requires Tab.
   114→   114→8. **Leader-key chords** (`g` then letter) for view/filter switching — Linear/GitHub/Vimium pattern, faster than `⌘K` for known destinations.
   115→   115→9. **Selection-highlight slide via Framer Motion `layoutId`** — the Linear/Raycast signature micro-interaction that makes J/K feel physical. LCKED has AnimatePresence but not the sliding highlight.
   116→   116→10. **Zero state-loss across lock/unlock** — LCKED must persist active item, scroll, search query, and unsaved editor drafts across lock. Critical for a password manager.
   117→   117→11. **WCAG 2.1.4 compliance** — single-key shortcuts must be disable-able, remappable, and/or focus-scoped (always off in text inputs). LCKED should implement all three.
   118→   118→12. **Native feel over web feel** (Raycast): no `cursor:pointer` on controls, no hover-everywhere, no flicker on transitions, popovers extend beyond bounds.
   119→   119→13. **14 named principles** synthesised (100ms Rule, Spatial Consistency, Frecency over Recency, No Dead-Ends, Zero State-Loss, One Palette Mode Prefixes, Modifier-Tiered Verbs, Quasimodes over Toggles, Contextual Actions, Deterministic Muscle-Memory Routes, Native Feel, Power-User ≠ Inaccessible, Simple First Then Powerful, The Tool Disappears).
   120→   120→14. **Ranked top-10 LCKED improvements** delivered (see brief §8), plus 10 honourable mentions.
